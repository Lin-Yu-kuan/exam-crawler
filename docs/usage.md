# 操作說明

> 本工具查詢考選部「考畢試題查詢平臺」的公開試題，先勾選目標考科，再下載試題與測驗答案並依模板歸檔。
> 搜尋與下載需要網路；已有快照的篩選、路徑預覽與檔案整理可離線進行。
> 本工具只在本機執行（Streamlit 僅監聽 `localhost`），檔案存在你自己的電腦。

## 1. 環境需求

| 項目 | 版本 |
| --- | --- |
| Python | 3.10 以上（本次驗收使用 3.14.7） |
| 作業系統 | Windows 10/11（本次驗收環境）；其他平台未實測 |
| 套件 | 見 `requirements.txt`（httpx 0.28.1、beautifulsoup4 4.15.0、lxml 6.1.3、pypdf 6.21.4、streamlit 1.66.1） |

安裝：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 2. 啟動

```powershell
.\.venv\Scripts\python.exe main.py
```

預設開啟 `http://localhost:8501`。瀏覽器的網路統計與使用率上報可用
`--browser.gatherUsageStats=false` 關閉。

## 3. 操作流程

1. **設定下載位置**（左側欄）
   - 下載根目錄：所有檔案都只會建立在此目錄內（含符號連結／junction 檢查）。
   - 資料庫檔案：預設為 `<根目錄>/manifest.db`，記錄快照與附件狀態。
   - 下載併發數：1～4，預設 2；所有請求仍受全域限速（啟動間隔 0.5～1.5 秒）。
   - 歸檔模式：A／B／C／D（見第 4 節）。
2. **查詢（按「開始過濾」）**：輸入年度（民國，含起迄），可再加**考試名稱／類科／科目**三個關鍵字（皆為選填）。
   - 關鍵字會先送官方進階查詢縮小範圍（例：科目「行政法」6.4 MB → 320 KB），再由本機以正規化字串確認
   - 關鍵字決定**快照範圍**：第二階段的候選清單只會列出符合的考試／類科／科目；要放寬需重新查詢
   - 勾選「不套用關鍵字，抓整年度全部考科」會忽略三個關鍵字、抓整年度（113 年約 3,566 筆／6 MB／11 秒），候選最完整但較慢
   - 勾選「重新向官網下載（忽略今日快取）」才會重新查詢；否則相同條件在 24 小時內直接用本機結果（0 請求）
   - 兩個勾選項的問號圖示有完整說明，滑過去即可看到
3. **確認快照**：畫面會顯示取得時間、狀態與筆數。
   - 狀態「完整」與「完整（統計差異）」都可下載；後者代表官方統計與實際列數不同（例如 113 年多 1 類科、2 科目），畫面會保留兩組數字。
   - 狀態為「結果未完整」「結果過大」「來源錯誤頁」「結構變更」時會停用下載，請重試或縮小年度範圍。
   - 官方單次查詢上限 6,000 筆，超過時會提示縮小條件（建議逐年查詢）。
4. **勾選候選**：考試／類科／科目三個區塊（只列符合第一階段關鍵字的項目），欄位之間是 AND、同一欄多選是 OR。
   - 「已選」以 chips 呈現：**點一下即叉除**，只更新本機選取，**不會重新查詢官方**；括號內為份數。
   - chips 一次最多列 40 個「目前可見」的已選項目；選很多時用快速過濾縮小範圍即可看到其餘。
   - 「從可見清單加入」為未選項目清單，可直接在框中輸入關鍵字搜尋。
   - 每個項目旁顯示「份數」＝目前其他欄位條件下的考科紀錄數。
   - 快速過濾只影響可見項目；「全選可見／取消可見／反選可見」也只作用於可見項目。
   - 任一個欄位零選取時無法下載。
   - 取消某欄位後，已不在候選池的已選值會自動移除（例如取消某考試後，該考試專屬的類科），所以「已選 N／總數」一定不會出現 N > 總數。
   - 只有變更第一階段條件、勾「重新向官網下載」或開始下載才會發出網路請求；叉除 chips 是純本機操作。
5. **預覽歸檔路徑**：按「計算預覽」才會計算（選取很多時需要數秒，畫面會顯示「計算中…」）。
   - 預覽只計算路徑，**不會建立或修改檔案**；表格上方會顯示「共 N 個檔案、M 個資料夾；其中 K 個題型暫定」。
   - 表格預設只列前 200 筆；題型「暫定」代表下載後會依實際 PDF 內容改名。
   - 改動任何選取、年度或歸檔模式後，舊預覽會自動失效，需要重新按一次。
6. **開始下載**：按一次即可，重複點擊或頁面重跑不會建立第二個任務。
   - 進度區顯示任務狀態與「新下載 N／共用 N／略過 N／失敗 N／取消 N」；已存在且校驗通過的檔案會計入「略過」（重跑 0 請求）。
   - 「共用」表示新下載內容完全相同的 PDF（SHA-256 相同），因此**不再寫第二份**，該筆紀錄指向既有檔案；檔案損壞或不存在時會自己寫一份。
   - 「預計歸檔 N 個檔案」以附件數估算，實際檔案數可能因共用而較少。
   - 可隨時「取消下載」；已完成的檔案會保留。
   - 試題成功但答案失敗時狀態為「部分完成」，可按「重試未完成」只重試失敗的附件。
7. **啟動核對**：每次啟動會自動檢查 `.parts` 暫存、已歸檔檔案與資料庫是否一致；補記完成、標記中斷並列出未追蹤檔案（不會自動覆寫）。

## 4. 歸檔模式與變數

| 模式 | 相對路徑模板 |
| --- | --- |
| A（預設） | `{科目}/{年度}_{考試名稱}_{類科}_{題型}.pdf` |
| B | `{年度}/{考試名稱}_{類科}/{科目}_{題型}.pdf` |
| C | `{年度}_{考試名稱}_{類科}_{科目}_{題型}.pdf` |
| D（自訂） | 使用下表的變數，檔名必須以 `{題型}.pdf` 結尾 |

| 變數 | 內容 |
| --- | --- |
| `{年度}` | 民國年度數字（例如 `113`） |
| `{年度標籤}` | `113年` |
| `{考試名稱}` | 官方全名（可能很長） |
| `{考試簡稱}` | 目前來源未提供簡稱，會回退為考試全名 |
| `{類科}`、`{科目}` | 來源原始值 |
| `{等別}` | 缺少資料時為「等別未確認」 |
| `{題型類別}` | 申論題／測驗題／混合題／未確認（答案採該考科整體題型） |
| `{題型}` | 申論試題／測驗試題／混合試題／試題／測驗答案 |

規則：
- 未知變數、格式運算、絕對路徑、`..`、反斜線與空目錄段一律拒絕。
- 檔名會清理非法字元、控制字元、尾端空白／句點與 Windows 保留名稱（如 `CON`）。
- 同一考科的試題與答案共用主檔名前綴；拆卷或碰撞時在題型前插入穩定短 ID。
- 內容更新會保留舊版，新檔名帶內容雜湊。

## 5. 題型判定

- 只讀 PDF 第一頁前 300 字元，不掃描其他頁、不做 OCR；嗅探在獨立程序中執行，逾時 5 秒。
- 明確混合敘述優先；純題型需排他證據（例如「全部為測驗題」或題數加總等於總題數）。
- 未取得證據時維持「未確認」，檔名為「試題」，仍會歸檔。
- 實際樣本的未知率偏高（見 `docs/acceptance.md` §5），請以檔名與 manifest 為準。

## 6. 疑難排解

| 症狀 | 可能原因與處理 |
| --- | --- |
| 畫面顯示「完整（統計差異）」 | 官方統計文字與實際列數不一致（不影響已渲染的紀錄）；可正常下載，請自行判斷是否接受 |
| 畫面顯示「查詢結果未完整」 | 解析失敗、超過 6,000 筆或合併後筆數不符；縮小年度或重試（詳見 `docs/source-validation.md`） |
| 查詢失敗並顯示 HTTP 403 | 來源拒絕存取，已停止對該來源的請求；請稍後再試 |
| 反覆出現 429／503 | 已依 Retry-After 暫停；降低併發數或稍後再試 |
| 下載失敗 `invalid-pdf` | 來源回傳 HTML 錯誤頁或檔案損壞；可重試，仍失敗請檢查網路與來源狀態 |
| 檔案沒有出現在預期位置 | 檢查錯誤訊息中的路徑設定；確認根目錄未被其他程式鎖定 |
| 想重新下載已完成的附件 | 刪除檔案後重新執行（會自動修復），或直接再按一次下載（已完成的會略過） |
| 想核對實際落地結果 | 執行 `python scripts/check_ui_downloads.py`：列出 PDF 檔數、大小與 manifest 的附件狀態／題型 |

## 7. 已知限制

- 官方沒有分頁，單一年度查詢就會回傳全部結果（6 MB 以上），且單次上限 6,000 筆。
- 不做位元組續傳；中斷後以「附件層級」重新下載。
- 題型判定保守，實測樣本多數維持「未確認」。
- 來源的「更正答案」會與原答案並存，兩者都歸為「測驗答案」，以穩定 ID 消歧。
- 同一份 PDF 若在不同類科下有不同的下載網址（內容相同），只會儲存一份，兩筆紀錄指向同一檔案（manifest 以 `dedupe_of` 記錄來源）；去重只看網址的「傳輸去重」與看清內容的「內容去重」是兩層。
- 遠端多人部署、OCR、申論解答生成不在本版範圍。
