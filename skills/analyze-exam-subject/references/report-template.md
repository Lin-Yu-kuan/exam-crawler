# 報告結構

1. **範圍與限制**：備考科目、勾選官方科目、年度／考試、來源檔案數、去重後內容數、已解析／失敗／待確認數、分析時間與分類版本。標示完整或部分完成。
2. **考點地圖**：主題、子主題、常見問法、相關題數、代表題來源。跨科交叉題清楚標示。
3. **命題分布**：按年度與考試分層；定義唯一題數、事件數、標籤命中數及百分比分母。不將未知事件當作獨立命題。
4. **準備建議**：觀察證據與 AI 建議分開，優先順序兼顧頻率、覆蓋年份與先備關係；資料稀少時不作趨勢推論。
5. **題目索引**：備考主題、官方科目、考試、年度、題號、PDF 頁碼及本機檔案連結；連結不支援頁碼時仍用文字列明頁碼。
6. **排除與待確認**：不相關題目的排除理由、不可判讀檔案、答案版本衝突、疑似重複題、未完成批次。

視覺版本另列選取頁數、文字擷取頁數、渲染頁數、已視覺核對頁數、未檢視／不可判讀／渲染失敗頁數。題目數未知時只報頁面覆蓋；連總頁數都未知時只報已知頁數與缺口，不產生百分比。圖表結論引用 PDF 頁碼及實際判讀圖片。未視覺核對的頁面產生待檢視清單，報告為部分完成，即使文字擷取全部成功也不例外。

所有重要結論附代表題來源；總計由 question-index.json 重算。只列觀察到的結果，不把示例數字或模板內容當成分析結果。
